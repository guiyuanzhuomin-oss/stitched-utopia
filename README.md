**一张破损车票穿过纸质城市，最终让“永远不存在的下一班”真正到站。**

## 作品思路：让歌词产生后果

主角不是人形角色，而是红色的“自由”车票和蓝色的“同行”车票。车票的折角、孔洞、裂痕和补丁贯穿全片；歌声通过收音机、纸带和信件在城市中传播。

我们没有只把歌词写在背景上，而是为它设计动作和结果：

| 歌词意象 | 画面中的事件 | 之后留下什么 |
| --- | --- | --- |
| 过亮的光将我们灼伤 | 印刷灯箱照射票根，留下灼痕 | 回归段中出现主动遮光的纸板 |
| 回忆像相册翻了又翻 | 相册在圆城内部实际翻页 | 两张车票的旧照片与后来留下的空缺 |
| 八小时清醒、做梦、种花 | 三个时钟进入蓝色城市图纸 | “乌托邦”拥有时间分工和具体空间 |
| 回头你却早就已经不见 | 夜街照片中的蓝票消失 | 结尾在同一路灯下重新相遇 |
| 活下去 | 接通机械 → 歌声送达 → 断桥通车 → 夜街听见 | 原本缺席的下一班车真正到站 |

## 一次关键修订

第一版已有圆形纸城、钴蓝蓝图和夜街，但网格占用的时间较长，高潮依赖花阵和抽象连线。创作者提出保留这三个场景，并补充歌词对应内容，彻底重做“活下去”之后的段落。

![左：V1 高潮；右：V2 的零件工作台](docs/images/revision.jpg)

*左为保存的 V1 初稿，右为最终 V2；两幅图分别来自约 97.3 秒的位置。*

V2 把网格压缩到 9.68 秒，增加灯箱、折叠地图、收音机、翻页相册、街边店铺、邮筒、信件和照片。四声“活下去”分别触发具体事件：一件零件重新工作，一封信被收到，一座桥可以通车，一个声音终于有了接收端。

修改同时落在动作细节上：票根随齿轮转动，信件进入邮筒开口，车轮接触桥面。场景切换依靠物件、动作和含义的传递。

## 技术如何服务画面

- **Canvas 2D 绘制：** 共用纸纹、撕边、网点、票根、字形和图元；复杂段落保留专门编写的场景函数。
- **手写伪三维：** 用尺度、遮挡、位移和二维变换表现街道纵深及纸张翻折，无 SVG、WebGL 或真实三维场景。
- **音乐时钟：** 有配乐时使用 `audio.currentTime`；离线导出使用 `frame / 60`。暂停和定位不会依赖之前的播放历史。
- **确定性渲染：** `UtopiaFilm.render(t)` 根据绝对时间与固定随机细节绘制，支持直接跳到任意时刻。
- **音频分析：** 保存低频、中频、高频、RMS 和 onset 包络，并用提供的行级 LRC 组织事件。估计节拍与直接听觉判断分别记录。
- **离线输出：** Chrome / Playwright 逐帧绘制，FFmpeg 编码 H.264 并合入 AAC 配乐。

实现细节、场景调度与验证范围见 [技术说明](docs/TECHNICAL.md)。

## 直接运行代码演示

下载仓库后双击根目录的 **[index.html](index.html)**。它是可离线运行的单文件代码演示，默认静音；点击“加载本地配乐”可选择本机的同版音频，文件仅由浏览器读取。

空格播放 / 暂停，方向键前后 5 秒，F 全屏。也可以使用下方时间条或场景快捷定位。想看到最终排版和原始配乐，请观看 Release 中的 MP4。

仓库不内置歌曲音频和商业字体文件。静音演示使用本机中文字体；字体差异可能改变部分字形。完整 MP4 为已经交付的最终作品。

## 编辑与复现

需要 Node.js 20+。渲染还需要 Chrome / Chromium 和 FFmpeg；系统已有 Chrome 时通常可直接使用。

```bash
npm install
npm run build       # 构建单文件代码演示；不需要音频
npm run frames      # 输出全片关键画面
npm run verify      # 检查演示播放、暂停、定位、音频时钟和确定性
```

若没有系统浏览器：

```bash
npx playwright-core install chromium
```

完整配乐导出需要自行提供 `assets/song.mp3`。可以使用 `npm run prepare -- --audio "your-song.mp3" --lyrics "your-lyrics.lrc"` 准备标准音频与歌词，再运行 `npm run analyze`、`npm run build`、`npm run render`。重新分析需要 Python、NumPy 和 FFmpeg。详细的路径覆盖、字体选择和导出说明见 [复现流程](docs/TECHNICAL.md#复现流程)。

```text
src/film.js           共用绘制、原圆城 / 吉他 / 蓝图、场景调度
src/scenes.js         V2 定制场景和具体动作
src/score.js          完整时间轴和音频包络
src/player.js         保存的原始 V2 音频播放器源码
src/demo-player.js    公开演示：静音播放或本地音频驱动
assets/score.json     可查看的测量结果、歌词和修正记录
prompts/             融合 skill、原始要求与修订反馈的完整 prompt
docs/                创作过程、技术、关键画面和交付证据
tools/               构建、音频准备、分析、逐帧导出和验证
```
