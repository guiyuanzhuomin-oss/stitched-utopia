# 从歌词到纸质城市

## 原始要求与创作边界

最初的要求是制作配乐代码动画，尽量不使用 SVG 或真实三维场景，必要时用代码实现伪三维。提供的素材是《拼接乌托邦》的歌曲文件与 LRC。

`sol-motion-director` 提供了导演原则：运动承担表达，重要动作产生后果，重复意象在回归时改变含义，结尾要改写前文建立的期待。角色采用非人、非人形的物件。这里选定车票，因为它天然关联“自由”“终点站”“下一班”与“同行”，能够以折角、灼痕、裂口和补丁保存经历。

完整的整合简报见 [COMPLETE_PROMPT.zh-CN.md](../prompts/COMPLETE_PROMPT.zh-CN.md)。它把 skill 与本次要求融合成可独立使用的 prompt，同时标明其中加入了最终修订的具体事件。

## 贯穿全片的物件

| 物件 | 首次作用 | 回归时的变化 |
| --- | --- | --- |
| 红色“自由”车票 | 受困、被灼伤、在地图中迷路 | 从废零件工作台重新接通传动装置 |
| 蓝色“同行”车票 | 旧照片里的陪伴 | 缺席后在同一条夜街重新出现 |
| 终点站与公交车 | 下一班永远缺席 | 断轨接成桥，公交车真的到站 |
| 收音机与歌声 | 歌唱穿过冷色城市 | 纸带成为传递路线，信有明确接收端 |
| 夜街路灯 | 照亮旧照片和灼痕 | 保留位置，最后照亮相遇 |

这些物件把音乐中的抽象情绪落实为状态变化。它们可以跨镜头传递含义，也可以在同一场景里继续动作。剪辑允许硬切、图形匹配和场景跳转；被建立的接触、身份和后果需要保留。

## 材料与画面组织

米白纤维纸承担票根、地图和相册；午夜蓝油墨承担城市与机械；朱红区分“自由”票与受力痕迹；钴蓝区分城市蓝图和声音传递；鹅黄用于灯光与公交车；薄荷色用于信件、声音路线和已经接通的关系。

圆形城市让“转啊转”具有空间形状，相册在圆环内部翻折。蓝图让“八小时”成为城市的时间分工。夜街用店铺、长椅、站牌、邮筒、信件和照片承载想念，纵深由二维投影和遮挡表现。

## 为什么 V2 改变了高潮

创作者喜欢圆形纸城、蓝图和夜街，要求保留；同时认为夜街需要更多歌词对应，网格段落过长，“活下去”之后过于抽象，需要彻底重做。

V2 继续使用已有视觉语言，增加灯箱、折叠地图和歌唱收音机。夜街得到更具体的生活物件，蓝票的消失留下了照片中的空缺。网格只保留 `0–5.13` 与 `79.23–83.78` 秒，总计 9.68 秒。

高潮的四个事件按提供的行级歌词时间展开：

| 起点 | 事件 | 可见结果 |
| --- | --- | --- |
| 95.18 s | 工作台接通 | 票根补入齿轮；“没用的零件”开始工作；印刷纸带输出 |
| 98.58 s | 歌声送达 | 收音机输出纸带；信件进入“寄给明天”邮筒 |
| 102.43 s | 架桥通车 | 断轨接成可以支撑车轮的桥；公交越过接缝 |
| 106.48 s | 夜街听见 | 公交到站；收音机与路灯亮起；两张车票重逢 |

结尾没有消除城市里的全部阴影。它只让之前“永远不存在”的一班车到来，让歌声有了接收端。这一变化为开场建立的困境提供具体回应。

## 动作也需要修订

设计一个“接通”场景还不够：票根进入齿轮后必须跟随转动；信件不能在邮筒旁凭空消失；车轮必须贴着桥面通过。V2 对这些接触关系做了修正，检查连续动作时把它们当作叙事的一部分。

初版与修订版工程均保留在本地。这个公开仓库发布最终 V2 核心源码与对照画面，不伪造过去的 Git 提交历史。
