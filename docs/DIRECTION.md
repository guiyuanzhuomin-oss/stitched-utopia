# 拼接乌托邦 · 下一班，听见你 · V2

114.92848 秒完整原曲，1920×1080 / 60 fps，全部由 Canvas 2D 绘制。圆城、纸张翻折、街道纵深是代码投影，不包含 SVG、WebGL 或真实 3D。没有人形人物。

核心动作：一张破损的“自由”车票穿过网、过亮的灯箱、迷路的折叠地图、收音机、圆城、相册、琴弦、蓝图和夜街。它在高潮中补入传动装置，原本没用的零件被重新接通，歌声送入信件，断轨成为可以通行的桥，终点站终于到来下一班车。仍有阴影的城市里，两张票在路灯下重逢。

材料延续米白纤维纸、午夜蓝油墨、朱红票根、钴蓝图纸和鹅黄灯光。薄荷色用于声音线路、信件和已通的接点。保留圆城与蓝图的构图语言，夜街增添同一城市里具体的店面、长椅、站牌、邮筒、信、旧照片与收到歌声的收音机。纸卷、金属齿轮、折页、印刷墨迹与车轮各有不同运动方式。

网格只保留 0–5.13 与 79.23–83.78 秒，共 9.68 秒。其余部分分别发展光的灼伤、地图分叉、收起尖角、歌声沿线路传播。圆城的两次相册段实际翻页并保留空缺。图三夜街从风中的信，发展到两张票的照片，再到蓝票不见、旧灯照着旧伤。

95.18 / 98.58 / 102.43 / 106.48 秒的四声“活下去”分别进入工作台接通、收音机送达、断桥通车、夜街听见。具体调度见 REVISION.md。最终到站、接收与重逢改写开场“永远不存在的下一班”。不把原来的花阵或辐射状缝线带入结尾。

红票的圆孔、锯齿边、印刷字和白补丁保持身份；蓝票在旧照片中的消失与结尾收到歌声后的出现对应。圆城的公交车、终点站牌、纸收音机与信件都在后文有可见结果。字进入印刷纸带、站牌、照片或地图的材料里。完整的行级字幕包含高潮里的括号反唱。

音乐时钟：实时播放由 audio.currentTime 驱动；导出由帧号/60 驱动并合入完整音频。信号估计 122.002 BPM、0.120 秒相位。低频用于受力，瞬态用于压印与接点，高频用于灯线和音信，机械转动与车行保持惯性。保持确定性随机细节，支持任意定位。
